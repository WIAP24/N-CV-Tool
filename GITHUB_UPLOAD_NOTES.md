# GitHub Upload Notes

This folder is a clean publishable copy of the NIRAS CV Screener app.

Included:
- Streamlit app source
- Python package source
- sanitized unit tests
- requirements files
- sample criteria
- README

Excluded:
- real CVs
- extracted CV text
- screening results
- generated Excel workbooks
- raw model outputs
- local cache folders
- Python bytecode
- virtual environments
- local secrets

Before publishing, create an empty GitHub repository and copy the contents of this folder into it.
